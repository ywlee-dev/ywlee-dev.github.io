앱 구조 기초 — 기계를 뜯어 보나, 코드를 뜯어 보나

예시는 Electron · Vue 앱이지만 Flutter · React 든 같은 모양이다. 그림 속 파일 이름은 설명용 예시.

기계 뚜껑을 열면 늘 세 가지가 보인다 — 움직이는 부품, 사이를 잇는 회로, 언제 움직일지 적힌 기준. 코드를 열어도 똑같이 세 가지다. 그래서 기계를 따라가듯 코드를 따라갈 수 있다.

6그래서 코드는 기계 뜯듯이 읽는다

  1. 뚜껑을 연다 — 팀 폴더를 연다. 파일 이름만 봐도 무엇이 든 상자인지 안다.
  2. 선부터 따라간다 — 🔌 .wiring 을 연다. 어느 장비에서 울려 어느 장비로 가나.
  3. 왜 그쪽으로 갔나 — 이음쇠가 물어본 📘 .rules 를 연다.
  4. 부품이 어떻게 움직이나 — 마지막에 ⚙️ .mech 를 연다.

다른 점도 있다. 전기는 붙어 있는 동안 계속 흐르지만, 코드의 fan.on() 은 한 번 부르고 끝난다. 진짜 릴레이에는 기준이 없고, 기준은 다이얼이나 PLC 프로그램처럼 따로 있다 — 우리가 룰을 따로 두는 것과 같다.
